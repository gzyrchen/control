频域稳定判据：一张图看「绕不绕 −1」，一张图看「穿不穿 −180°」

闭环稳定的充要条件，奈奎斯特说是 Z = P − 2N（曲线绕 −1 点的圈数），伯德说是「在 L(ω)>0 的频段里，相频曲线对 −180° 线的净穿越次数等于 P/2」。 这两句话听起来毫不相干，其实是同一件事的两件外衣。拖一下增益 K，看两个计数怎么同步变化；点“同步游标”，看同一个 ω 在两个坐标系里的同一个点。 把 K 拖过临界，再看第二排——闭环极点跨过虚轴的那一下，阶跃响应正好由收敛翻成发散。
判据只回答「稳不稳」，裕度回答「离悬崖还有多远」：γ 量在 ωc（|G|=1 处，相位到 −180° 的余量），h 量在 ωg（φ=−180° 处，幅值到 0 dB 的余量），两个频率与两个数值都标在图上和面板里。

1判据在问一个几何问题

闭环特征方程 1 + G(s) = 0，等价于 G(s) = −1。所以开环曲线有没有「套住」−1 点，决定了闭环极点在不在右半平面。

辐角原理给出 Z = P − 2N：P 是开环自己就有的右半平面极点，N 是曲线逆时针绕 −1 的圈数。P 是欠的债，N 是还的债。

图上只画了 ω: 0→∞ 的上半支——负频率那半支是它关于实轴的镜像，贡献同样多的圈数，所以判据里要乘 2。

2绕 1 圈 = 穿 1 次

把复平面摊成伯德图：|G|=1 变成 0 dB 线，∠G=−180° 变成 −180° 线。曲线两次穿过负实轴之间，就是相频穿过一次 −180° 线。

所以「绕 −1 几圈」= 「在 L>0 的频段里，相位净穿 −180° 几次」。图上橙色的那段弧和橙色的那片频段，是同一批 ω。

3为什么只数 L>0 的部分

绕不绕 −1，只看曲线离原点多远：|G|>1 才有资格「跑到 −1 的外面」。|G|<1 的那半段，无论相位怎么转，都在单位圆里面，压根碰不到 −1。

这就是伯德判据里「只数 L(ω)>0 频段」的来历——不是规定，是几何必然。

4P ≠ 0 时最反直觉的一步

选「含右半平面极点」那个对象：开环自己就有一个右半平面极点（P=1），可它照样能闭环稳定——只要曲线逆时针绕 −1 半圈。

半圈怎么来的？曲线在 ω=0 处正好落在 −180° 线上（G(j0)<0），于是「起点」就是一次半穿越。这个 0.5 是本页最容易数错的地方。

5稳定裕度是「离悬崖多远」

两个指标各带着自己的频率：γ = 180° + φ(ωc) 量在 ωc（|G|=1、L 穿过 0 dB 处）；h = −20lg|G(ωg)| 量在 ωg（φ 穿过 −180° 处）。

图上就是两段竖直距离：相频上 φ(ωc) 到 −180° 线那一段是 γ，幅频上 L(ωg) 到 0 dB 线那一段是 h。奈图换同一个意思：γ 是原点到 |G|=1 那点的射线与负实轴的夹角；h 里被量的其实是 |G(ωg)| 本身，图上就是原点 → 负实轴穿轴点那一段（洋红量尺），拿它跟单位圆（半径 1）比长短即可——没到 1 还有余量，越过 1 就是已经不稳。

h 还能折算成「K 最多再乘几倍」：1/|G(ωg)| = 10^(h/20)，乘到它就正好压上 −1。量尺是线性长度、不是 dB 刻度——按长度比例去读 dB 必然算错（|G|=0.5 时条只有一半长，却是 6 dB），所以奈图里不标 dB，只把倍数连同 = 1/|G(ωg)| 写进图例（其中 |G(ωg)| 用洋红加粗，与量尺对应）；dB 读数看伯德图与面板，那里才是对数刻度。

两个裕度都默认「最小相位 + 各自只穿越一次」。含右半平面极点的那个对象（P=1）相位只在两端贴着 −180° 走，没有实义穿越——面板会显示「无定义」，这不是算错，是前提不成立。

6使用边界

判据要求开环传函在虚轴上无极点（否则要补小半圆或改用别的处理），且 ω 从 0 扫到 ∞ 时曲线不穿过 −1（穿过就是临界，此时它只告诉你「有一对纯虚根」）。

还有一层：Z 只数右半平面的极点。极点如果正落在虚轴上，Z 照样是 0——它查不出这种临界。把四阶对象的 K 拖到 126 就能看到：判定卡还写 0，可极点已经贴在虚轴上了。

本页三个对象都不含积分环节。含 1/s 的系统要在 ω→0 处补一段无穷大圆弧，那是另一套手续，不能直接套这里的数字。
