频域稳定判据 · 含积分环节的补画与统一规则

含 v 重积分环节时 s = 0 是虚轴上的极点，Nyquist 路径要在原点绕开；映射到 G 平面，正频段实线曲线在 ω→0⁺ 处停在无穷远，方向是 φ(0⁺)。补画只有一句话：从 ω=0⁺ 的实线起点出发，逆时针补 v×90°，补到 ω=0 的方向——最小相位对象大多补到正实轴无穷远。补完之后，扫描路径就是完整的 ω: 0 → 0⁺ → ∞。
补画之后，剩下的判据与不含积分环节完全一样：数整条曲线绕 (−1, j0) 的圈数 N，代入 Z = P − 2N；等价地，在 L(ω)>0 频段数 −180° 线净穿越 N⁺−N⁻，稳定要求 N = P/2。补画段已计入 N，公式与稳定条件两页通用。
四个对象：A、C 对任意 K 稳定，B 有临界 Kc = 6；新增的非最小相位 D = K/[s(s−1)(s+2)]（P = 1）从 −270° 无穷远逆时针补 90° 到负实轴无穷远，给出半次负穿越，N = −½、Z = 2——规则照旧，只是这笔半次要算清楚。右上「显示补画弧」只管画面；拖 K 看曲线怎么把 −1 圈进去。

1补画：从 ω=0⁺ 逆时针补 v×90°

s = 0 是虚轴上的极点，Nyquist 路径在 s 平面要用半径 ε 的小半圆绕开原点。它的像不会变小：G ≈ A·ε−v·ejψ，幅值发散而方向确定，在 G 平面上就是一段半径无穷大的圆弧。

落到正频段曲线上，规则是：以 ω=0⁺ 的实线起点为出发点，逆时针补 v×90°，终点是 ω=0 的方向。v=1 从 −90° 补到 0°，v=2 从 −180° 补到 0°，两者都补到正实轴无穷远。

显示口径：紫色弧按显示半径 Rw 示意，不是等比缩放；|G|>Rw 的低频实线被取景截断，所以实线断口与补画弧的 ω=0⁺ 端在图上不重合——两者同属 ω=0⁺ 方向，中间是省略的无穷远段。

2补完就完整：ω: 0 → 0⁺ → ∞

补画把断在无穷远的两头接上，正频段成为一条连续完整的曲线：ω=0（补画终点）→ 补画段 → ω=0⁺（实线起点）→ 实线段 → ω→∞。

注意遍历次序：作图时从 ω=0⁺ 逆时针补画到 ω=0；按 ω 递增读完整曲线时，补画段是从 ω=0 走回 ω=0⁺，方向相反。这只是读法不同，绕数与穿越计数都按 ω 递增那一条序列算。

画面上紫色箭头标的是作图方向（逆时针），两端分别写 ω=0⁺ 与 ω=0；按 ω 递增读图时方向相反，判据数值不受影响。

3规则同前：Z = P − 2N

补画之后，判据与不含积分环节逐字相同：数完整曲线绕 (−1, j0) 的圈数 N，代入 Z = P − 2N。P 只数开环右半平面极点，原点上的 v 重极点不计入 P。

稳定要求 Z = 0，即 N = P/2。伯德图那条路也照旧：在 L(ω)>0 频段数 −180° 线净穿越 N⁺−N⁻，它应当等于 N。

补画段是完整曲线的一部分，N 已经计入它的贡献。P、N、Z 只用上面这一组关系，稳定条件始终是 N = P/2。

4补画段在伯德图上怎么数

补画段 |G|→∞，整段都在 L(ω)>0（0 dB 以上），不存在「因幅值小于 1 而不计」的情形。相位从 φ(0⁺) 连续变到 φ(0)，途中若跨过 −180° 线，按完整穿越计入净穿越。

端点恰好压在 −180° 线上时记半次：向上离开 +½、向下离开 −½。伯德图左边框那支紫色箭头就是补画段，半次穿越画成空心圈。

渐近贴线不算穿越：判据与 γ / h 只在 0.02 ~ 500 rad/s 频段内量取，避免把曲线两端「贴着 −180° 走」误读成穿越。

5非最小相位例子 D

G(s) = K/[s(s−1)(s+2)] = K/(s³+s²−2s)，开环有 P = 1 个右半平面极点（s = +1），另有 v = 1 重积分。

按连续相位口径 φ(0⁺) = −270°，逆时针补 90° 到 −180°（负实轴无穷远）。这个终点正压在 −180° 线上，构成半次负穿越：N⁺−N⁻ = −½，完整曲线绕数 N = −½。

代入同一式：Z = P − 2N = 1 − 2×(−½) = 2，闭环有 2 个右半平面极点，与 Routh 表一致。若要稳定，P=1 应要求 N = +½，而 D 给的是 −½。

D 的相位始终低于 −180°，没有有限的 ω_g；判稳依据 Z = P − 2N 与净穿越次数，幅值裕度 h 在该对象上无有限读数。

6与上一页的接口 · 计算口径

上一页的对象在虚轴上无极点，ω: 0⁺ → ∞ 本身就是完整曲线；本页四个对象在原点有 v 重极点，要先补画才完整。两页的公式、判据、稳定要求完全相同，唯一差别是「补画」这一步手续。

计算口径：① P 只数开环右半平面极点；② N 是正频段（含补画）曲线相对 −1 的相角累积除以 2π，正负频率共轭故 Z = P − 2N；③ γ / h 是相对稳定性读数，对 P>0、闭环不稳的对象不能替代 Z 结论；④ 闭环极点用 Routh 表与 Durand–Kerner 求根两条独立路径核对。

判据只查右半平面：极点正落在虚轴上时 Z 仍为 0。把 B 的 K 拖到 6 就看得到——判定卡还说 0，极点已经贴到虚轴上了。
