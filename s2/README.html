一阶 / 二阶系统的时域响应：四种输入，一条曲线的四张脸

脉冲、阶跃、斜坡、加速度，四个公式背起来像四件事。但对线性系统，它们互为微分与积分： 脉冲响应就是阶跃响应的斜率，斜坡响应是阶跃响应的积分，加速度响应再积一次。 所以只要知道 g(t)，四条曲线就全定了——切换输入时盯住这一点，比分别记公式省力得多。

1四种输入是一家人

线性系统对输入是线性的，对运算也是：输入求导，输出就求导；输入积分，输出就积分。因为 δ(t)=1′(t)、t=∫1、t²/2=∫∫1，所以四条响应是同一条 g(t) 的微分/积分链。

一阶验证：g=1−e^(−t/T) → g′=(1/T)e^(−t/T)（正是 h）→ ∫g=t−T+Te^(−t/T)（正是斜坡响应）。三行是同一个东西。

记一条就够：知道 g(t)，另三条求导/积分即得。

2一阶只有一个数：T

T 是时间常数，整条曲线只由它一个数决定：阶跃到 63.2% 用 T，到 95% 用 3T，到 98.2% 用 4T；初始斜率恰好 1/T。

脉冲响应更直接：h(t)=(1/T)e^(−t/T)，h(0⁺)=1/T。T 越小冲得越高、衰减越快——这就是"反应快"的数学含义。

一阶永远不振荡、不超调，因为只有一个实极点，没有共轭复根可以引起摆动。

3二阶有两个数，分工不同

ζ 管形态与超调：σ% = e^(−πζ/√(1−ζ²))，只跟 ζ 有关，与 ωₙ 完全无关。ωₙ 管快慢：它只压缩或拉伸时间轴，t_p=π/ω_d，t_s≈4/(ζωₙ)。

所以拖 ωₙ 时曲线形状不变、只是横向伸缩；拖 ζ 时形状才真的变（ζ<1 振荡，ζ=1 临界，ζ>1 两个实极点、单调爬升）。

σ% 公式只对无零点的标准二阶成立。真实系统带零点时超调会明显偏大，不能直接套。

4型别：为什么斜坡差一个常数

两者的等效开环都含一个 1/s（一阶 1/(Ts)、二阶 ωₙ²/[s(s+2ζωₙ)]），都是 Ⅰ 型系统。

Ⅰ 型对阶跃：稳态误差 0；对斜坡：误差是一个常数（一阶 = T，二阶 = 2ζ/ωₙ），表现为输出永远落后输入这么一段；对加速度：误差随 t 线性增长，发散。

这就是实际系统要串积分环节提高型别的原因——但要付相位代价（见频域稳定判据那一页）。

5相对阶决定 t=0 的瞬间

一阶 Φ(s) 的相对阶是 1，脉冲响应在 t=0 有跳变，跳到 1/T；二阶相对阶是 2，脉冲响应 h(0)=0，从零起步，初始斜率才是 ωₙ²。

所以二阶脉冲曲线必须"从 0 起来再冲高"，而一阶是"一上来就最高然后一路衰减"。这不是画法差异，是阶次决定的。

另外：脉冲响应的面积恒等于 1（= Φ(0) 直流增益），两条曲线面积一样，只是形状不同。

6这张图是怎么算出来的

曲线不是套解析式画的，是状态方程 RK4 数值积分：一阶 x′=(u−x)/T；二阶 x₁′=x₂, x₂′=ωₙ²(u−x₁)−2ζωₙx₂。冲激输入按相对阶给初值（一阶 x(0⁺)=1/T，二阶 x₂(0⁺)=ωₙ²），其余三种把 u(t) 直接代入。

左下角那行小字是把数值解与闭式解逐点相减的最大相对偏差——一阶四种输入、二阶脉冲与阶跃都有闭式，可以硬对。

斜坡与加速度的误差"稳态值"只在极限意义下存在；有限窗口里看到的是趋势（恒定差距 / 越拉越大），别把窗口末端当成稳态。
