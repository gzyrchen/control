工程设计值 · 典型系统公式对照

h = 5 · Δ = 5%

1 物理模型与传递函数

电枢回路电压平衡：U_d − E = R(T_l s + 1) I_d，所以 I_d/(U_d − E) = (1/R)/(T_l s + 1)。反电势 E = C_e n 在电流环快速调节期间可视为缓慢扰动，设计内环时先忽略。

机电方程 T_e − T_L = (GD²/375) dn/dt，定义机电时间常数 T_m = GD²R/(375 C_e C_m)，在空载下得到 n/I_d = R/(C_e T_m s)：一个积分环节。

整流装置 K_s/(T_s s+1)，电流反馈 β/(T_oi s+1)，转速反馈 α/(T_on s+1)。本页用教材例题参数： R=0.5 Ω、T_l=0.03 s、T_m=0.18 s、C_e=0.132、K_s=40、 T_s=1.7 ms、T_oi=2 ms、T_on=10 ms、β=0.05 V/A、α=0.007 V·min/r。

2 六步动态结构图等效变换

  1. 原始双闭环：外环 ASR 的输出是内环电流给定 U_i*；反电势 −C_e n 反馈到电枢回路输入端。
  2. 取出电流环：忽略反电势扰动，把 T_s 与 T_oi 两个小惯性合并为 T_Σi = T_s + T_oi，丢弃高阶项 T_s T_oi s²。
  3. 整定成典型 I 型：令 ACR 的 PI 零点 τ_i = T_l 对消电枢大惯性，再取 K_I T_Σi = 0.5。
  4. 内环闭环等效：Φ_i(s) = 1/(2T_Σi²s² + 2T_Σi s + 1) ≈ 1/(2T_Σi s + 1)，电流环在外环眼里就是一个小惯性环节。
  5. 外环等效：把转速反馈滤波移到环内，合并 T_Σn = 2T_Σi + T_on，同样忽略 2T_Σi·T_on·s²。
  6. 整定成典型 II 型：取中频宽 h = τ_n/T_Σn = 5，按 K_N = (h+1)/(2h²T_Σn²) 定 ASR。

合并小惯性只在中低频成立。绿虚线给出未合并的原始开环：高频会多出极点，因而幅值裕度不再是 ∞。工程整定用的是中频段，不能用近似模型去读高频稳定裕度。

3 先内环、后外环

第一步 · ACR：τ_i = T_l，K_i = T_l R/(2 K_s β T_Σi)， 导出 K_I = K_i K_s β/(τ_i R) = 1/(2T_Σi)。电流环开环变成 W_i(s) = K_I/[s(T_Σi s+1)]，典型 I 型。

第二步 · ASR：先把电流环写成 1/[β(2T_Σi s+1)]，与机械积分、转速滤波一起得到 W_n(s) = K_N(τ_n s+1)/[s²(T_Σn s+1)]，典型 II 型。 K_N = K_n α R/(τ_n β C_e T_m)，故 K_n = K_N τ_n β C_e T_m/(α R)。

顺序不能反：外环整定时必须已知内环等效传递函数。点击「① 先整定电流环」只回填内环参数；「② 再整定转速环」才回填外环参数；「按工程设计法整定」一次走完两步。

4 典型系统性能公式

典型 I 型（K_I T_Σi = 0.5）：闭环特征式 2T_Σi²s² + 2T_Σi s + 1 = 0， ξ = 0.707，σ ≈ 4.32%，t_r = 4.712 T_Σi，t_p = 2π T_Σi。 本页数值解：σ = 4.321%、t_r = 0.01744 s、t_p = 0.02325 s。

典型 II 型（h = 5，Δ = 5%）：查表 σ ≈ 37.6%、t_r ≈ 2.85 T_Σn、 t_s ≈ 9.55 T_Σn。本页数值解：σ = 37.559%、t_r = 0.04981 s = 2.86 T、 t_s = 0.1669 s = 9.59 T。

上升时间按「首次到达稳态值」定义，调节时间按「最后一次离开 ±Δ 误差带」定义。因此典型 I 型在 Δ=5% 时超调本身只有 4.32%，t_s 会小于 t_r，这不是算错。

5 三种图如何互相印证

伯德图：蓝 / 橙是合并小惯性后的工程模型，绿虚线是保留 T_s、T_oi、T_on 的原始模型。工程整定点电流环精确 ω_c = 122.997 rad/s, γ = 65.53°；渐近公式给 ω_c ≈ K_I = 135.14 rad/s, γ ≈ 63.43°。转速环精确 ω_c = 32.009 rad/s, γ = 41.13°；渐近设计值 ω_c = 34.483 rad/s, γ = 40.60°。差异来自对数幅频渐近线。

根轨迹：以环路增益 K 为变量，× 为开环极点、○ 为开环零点、● 为当前闭环极点。设计点电流环在 τ_i = T_l 时发生零极点相消，根轨迹等效为二阶；转速环两支从原点出发形成共轭复极点。

阶跃响应由闭环传递函数零初值数值求解，指标不套近似公式；理论面板把「公式 / 查表值」和「本页现算」并排显示。完整双闭环还叠加了典型 II 型等效曲线，便于看合并小惯性带来的偏差。

6 模型边界与易错点

单位阶跃已做标幺化。转速给定按 n* / α 归一，电流给定按 β I_d* 归一，因此稳态值都是 1；若直接加 1 V 给定，实际转速稳态会是 1/α，数值看着会莫名大。

完整双闭环响应保留电流环一阶等效、机械积分与独立的 α/(T_on s+1) 反馈滤波；输出到实际转速 n(t) 时会带一个 (T_on s+1) 零点，所以超调约 44.38%，比典型 II 型的 37.56% 大。典型 II 型公式对应的是等效变换后、合并小惯性的反馈通道，不是未经等效的原始高阶对象。

稳定性：若滑块把闭环极点推到右半平面，页面标红「响应发散」，σ、tp、tr、ts 均显示「—」，但伯德图与根轨迹仍照常显示，便于观察失稳过程。
