1 状态空间平均法（课程建模四步）

取状态 x = [i_L, v_o]ᵀ、输入 u = v_g、控制量 d。CCM 下每个开关周期只有两个线性电路：

  1. 写 ON 态 ẋ = A₁x + B₁v_g 与 OFF 态 ẋ = A₂x + B₂v_g；
  2. 按占空比加权平均：A = dA₁ + (1−d)A₂、B = dB₁ + (1−d)B₂；
  3. 令 ẋ = 0 解稳态工作点 X、D；
  4. 加小扰动 x = X + x̂、d = D + d̂，丢掉二阶小量 d̂·x̂ 得线性小信号模型。

本页参数：V_g = 24 V、V_o = 12 V、D = 0.5、L = 220 μH、C = 470 μF、R = 2.4 Ω、f_s = 100 kHz。

2 复域数学模型与负载阻抗

令 D_n(s) = LCs² + (L/R)s + 1，在 v̂_g = 0 下解出：

G_vd(s) = V_g / D_n(s)、G_id(s) = V_g(Cs + 1/R)/D_n(s)、G_vg(s) = D / D_n(s)。

两式相除得 G_vd/G_id = 1/(Cs+1/R) = Z(s)，正是输出侧负载阻抗——双环等效变换的关键一步。LC 双极点 f₀ = 494.95 Hz、Q = 3.508（谐振峰约 +10.9 dB）；负载零点 1/(RC) = 141.09 Hz。

课程理想模型不含电容 ESR，因此 G_vd 没有 ESR 零点。实际样机高频相位会少滞后 90°，本页的补偿参数不能直接照搬到硬件。

3 先内环：电感电流环整定

内环 C_i(s) = K_pi(s + ω_zi)/s，开环 L_i = C_i·F_m·R_i·G_id。高频段 G_id ≈ V_g/(Ls) 只有一个极点， 把 PI 零点放在 f_zi = f_ci/10，交越处 PI 近似纯比例，于是 γ_i ≈ 84.3°。

本页由 |L_i(jω_ci)| = 1 精确解出 K_pi = 0.283744（不是只靠渐近线 ω_ci L/V_g）。检测与调制增益按课程传递函数框图标幺化为 1：F_m = 1/V_m = 1、R_i = H_v = 1。

内环闭环 T_i = L_i/(1+L_i)，外环看到的等效对象是 G_p(s) = Z(s)·T_i(s)：三阶、直流增益 R， 低频近似一阶惯性，这正是外环能用简单 PI 校正的前提。

4 频域法设计外环补偿网络

补偿器取 C_v(s) = K_c(s+ω_z)/[s(s+ω_p)]：原点极点保证零稳态误差，零点 ω_z 抬相位，高频极点 ω_p 抑制开关噪声。 外环开环 L_o = C_v·G_p。

频域整定三步：① 选目标截止 f_c（本页 1 kHz，约 f_s/100）；② 选 γ，按 f_z ≈ f_c/5、f_p ≈ 5f_c 布置零极点；③ 由 |L_o(jω_c)| = 1 反解 K_c。

推荐点：f_z = 200 Hz、f_p = 5 kHz、γ = 67.80°、h = 18.80 dB @ 4.705 kHz、K_c = 8.9215×10⁴。

关掉「自动定标」后 K_c 可手动拖，此时 f_c 变成实测交越频率，橙标记会跟着走，不再是设计目标。

5 相角裕度 ↔ 超调量

二阶系统 γ = arctan[2ζ/√(√(1+4ζ⁴)−2ζ²)]、σ = 100·e^(−πζ/√(1−ζ²))。图中灰虚线是这条理论曲线， 蓝点是保持 f_p、f_c、K_c 定标不变、只扫 f_z 时本页五阶闭环的实测 (γ, σ)。

趋势一致：γ ↓ → σ ↑。但两条线不重合——五阶系统还有一对高频闭环极点与一个零点，二阶公式只在中频段近似成立。 例如 γ = 40.4° 时二阶公式给约 28%，本页实测 35.1%。

注意 Δ=5% 且超调很小时，t_s 可能小于 t_r（响应一进误差带就不再出来），这不是算错。

6 模型边界与易错点

小信号、连续导通、平均模型。阶跃是给定电压叠加 0.2~2 V 的小扰动 Δv_o，不是从 0 V 启动到大占空比； 不含 PWM 饱和、开关纹波、采样保持与数字延时，也不含 ESR / 电感 DCR。

单位。G_vd 单位 V（每单位占空比）、G_id 单位 A；G_p = v_o/i_ref 单位 Ω； C_v = i_ref/v_error 单位 Ω⁻¹·s⁻¹ 量级，所以 K_c 数值看起来大是正常的。

失稳工况。若把零点推到截止频率以上，γ 会变负、闭环极点进入右半平面，响应标红「发散」，伯德图仍照常显示，方便观察失稳过程。
